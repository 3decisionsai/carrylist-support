# Carrylist Support

Carrylist is an offline packing and return checklist for iPhone.

## Plan and pack
Choose a template or Start fresh. Add traveler names separated by commas. Tap an item's circle to check it, or its name to edit the quantity, traveler, bag or note. Filter by traveler or bag, or search for an item.

## Bring it home
The return checklist has independent progress. Turn off Bring this home for gifts or things you will leave behind. Archive old trips or duplicate them for another journey.

## Backups
Open Settings to export a JSON backup to Files. Import adds copies without overwriting your current trips. Deleting the app removes its local data; export first if you want to keep a copy.
